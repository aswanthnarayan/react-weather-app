# Weather App 🌦️

A simple and responsive weather app built using **React**, **Vite**, **Axios**, and **Tailwind CSS**. It allows users to search for real-time weather data by city name.

## 🌐 Live Demo

👉 [View Live App](https://weather-app-react-aswanth.netlify.app/)

## ✨ Features

- 🌍 Search for weather by city
- 🌡️ View temperature, weather condition, humidity, wind speed
- ☁️ Display weather icons
- 📱 Fully responsive UI
- ⚡ Fast performance using Vite

## 🛠 Tech Stack

- **React 18**
- **Vite**
- **Axios**
- **Tailwind CSS**
- **React Icons**
